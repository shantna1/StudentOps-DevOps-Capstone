# Upgrade existing StudentOps
Keep your original folder and .env. Back up your database first. Stop containers with `docker compose down` (never use -v). Copy app.py, compose.yaml and templates/ from this archive into the existing StudentOps folder, replacing matching files. Run `docker compose up --build -d`, then `docker compose exec app flask --app app seed-demo`. Open http://localhost:8080/. New tables are created by init-db; existing student columns are unchanged. Demo seed adds 20 fictional students, fees, attendance and five classes; existing demo rolls are skipped. Attendance percentage counts leave as not present. Fee amounts are cumulative, not a payment ledger. Timetable supports adding/deleting classes, not clash detection. All previous DevOps files remain; publish a new image before deploying to Kubernetes. Jenkins may also use port 8080; use a different host port for Jenkins or StudentOps if needed.
